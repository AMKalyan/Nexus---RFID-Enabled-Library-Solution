# Synthetic Data and Credentials Declaration

SOP reference: §9 Stage 1 ("Confirm that all data and credentials are synthetic") and §10 (Secrets, Data protection).

I confirm that, for the Nexus candidate exercise:

1. **No real personal data** is used anywhere in this repository, its database seeds, test fixtures, sample spreadsheets, screenshots or demonstration. All names, emails, phone numbers, card numbers and smart-card UIDs are generated by the synthetic data generators (Faker with a fixed seed) or are obviously fictitious (`*@example.org`, `+91-00000-0xxxx`).
2. **No real bibliographic export from any institution** is used. Bibliographic records are generated, and ISBNs are generated with valid check digits but are not looked up.
3. **No real credentials, tokens, certificates or private keys** are committed. Every secret is generated locally at install time or read from a git-ignored `.env` file. `.env.example` contains placeholders only.
4. **No connection is made to any production system**, institutional network or live third-party service (email, SMS, CCTV, ILMS, RFID vendor cloud).
5. **Demo accounts** (one per role) use passwords generated by the seed script and printed once to the local console. They are not documented in the repository.

Controls that enforce this declaration:

| Control | Where |
|---|---|
| Git ignore rules for `.env`, keys, certificates, backups, generated spreadsheets | `.gitignore` |
| Secret scan and dependency audit in the build pipeline | Stage 3 CI configuration |
| Log masking of email, phone, smart-card UID and names | `backend/app/core/logging` (Stage 3) |
| Seed generators with fixed random seed for reproducibility | `backend/app/db/seed`, `migration/gen_sample.py` |
