# D8: Operations Package

Operational documentation for Nexus release 1.0.2. Everything here describes the prototype as built: every device, camera, email, SMS and print channel is a mock, and all data is synthetic.

| Document | Audience | Contents |
|---|---|---|
| [administrator-guide.md](administrator-guide.md) | Administrators | Staff users and roles, circulation policies, devices and keys, NCIP agencies, migrations, audit review, settings, licence activation |
| [user-guide.md](user-guide.md) | All staff and patrons | Signing in, then one section per role (Admin, Librarian, Circulation Clerk, Auditor, Patron) with screenshots |
| [api-guide.md](api-guide.md) | Integrators | Authentication, error format and codes, circulation refusal codes, device event contract, WebSockets, NCIP 2.0 subset, SIP2, rate limits |
| [device-configuration.md](device-configuration.md) | Administrators, integrators | Device table, registering a device, rotating its key, simulator configuration |
| [troubleshooting-runbook.md](troubleshooting-runbook.md) | Operators | Symptom, check and fix for the common failures |
| [training-plan.md](training-plan.md) | Trainers | Sessions per role, simulator exercises, assessment checklist |
| [openapi.json](openapi.json) | Integrators | OpenAPI 3 export of the REST API. The live version is served at `/api/docs` and `/api/openapi.json` |
